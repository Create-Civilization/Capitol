# To-do
A folder for a list of tasks that may be required to complete the main tasks, to avoid scope-creep, tasks will be accepted into
the main tasklist from backlog when all main tasks are done.

For simple tasks you can implement them here in a list:
- [ ] [Database](database.md)
- [ ] [Claim Protection](claim_protection.md)
- [ ] [Permission Manager](permission_manager.md)

If your task is larger than a quick patch, a simple, easy to explain task, make a new file (preferably linked here), again, all tasks created should stem
from a main task and should help complete them, if your task only polishes a main task, put it in [backlog](../backlog) instead.
